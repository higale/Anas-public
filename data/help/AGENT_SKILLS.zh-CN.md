# Anas 技能手册

语言：[English](./AGENT_SKILLS.en.md) | [中文](./AGENT_SKILLS.zh-CN.md) · [返回用户手册](./USER_GUIDE.zh-CN.md)

技能是一组供 Agent 按需读取的操作说明，可附带脚本和参考资料。启用技能不会自动安装依赖或开启工具权限。

## 添加与管理

在“设置 > 技能”中管理全局来源，浏览技能说明和文件。文件只读；点击技能详情底部的“技能位置”路径可在文件管理器中定位。文件预览和来源目录仍提供“打开”按钮。

- **导入技能**：选中“用户”分组或其中的技能，点击“导入”。选择一个或多个包含 `SKILL.md` 的技能目录，复制到应用数据目录的 `skills/`；重名时不导入、不覆盖。导入窗口默认打开示例目录。
- **添加目录**：选择包含多个技能子目录的外部目录，直接引用其中的文件，不复制。外部来源可改名、设置快捷别名、排序或移除；移除只删除引用，不删除文件。
- **项目技能**：放在项目各源文件夹的 `.agents/skills/` 下，在对应项目的能力列表和会话中使用，不出现在全局技能页。

`~/.agents/skills` 是默认外部来源，可以移除。修改文件后，点击刷新重新读取；无法读取的技能会显示错误。

## 谁可以使用

“模型可用”和“用户可用”分别控制两种用法：

- **模型可用**：向 Agent 提供名称、用途和 `SKILL.md` 绝对路径，让它按任务需要读取说明。
- **用户可用**：可在消息输入框用 `/技能名 用户需求` 主动调用；输入 `/` 可查看候选。Anas 将完整 `SKILL.md` 原文及来源路径直接发送给模型，调用后的文字作为独立的用户需求，可展开会话中的技能记录查看实际发送内容。

全局开关是默认值。在项目“定制能力 > 技能”中，选择“使用默认”沿用全局设置；选择“自定义”可分别指定两种用法，包括启用全局关闭的技能。关闭技能总开关会保留选择，但停止提供技能目录和快捷调用。加载失败的技能仍不可用。

子 Agent 只配置模型使用范围，可单独启用“项目技能”，并遵循项目的“限制子 Agent 能力”设置。详见[子 Agent](./USER_GUIDE.zh-CN.md#子-agent)。

同名技能分别按模型、用户的有效选择确定优先项：项目源文件夹顺序 → 用户 → 外部目录顺序 → 系统。`/name` 使用优先项；`/name@alias` 可指定来源，例如 `/name@user`。外部来源的别名可在技能页修改。

## 脚本免审

技能页右上角的“全部 Skill 脚本免审”和技能详情的“脚本免审”默认关闭，任一开启即生效。全局开启时保留各技能设置，关闭全局后重新按各技能设置执行。技能列表中绿色名称表示该技能单独开启了免审，不受全局开关影响。

脚本继续使用现有 Shell 工具。Windows PowerShell 和 macOS 系统 zsh 可识别单条“执行器 + 脚本文件 + 字面量参数”，例如 `python scripts/query.py --month 2026-09`；相对路径以工具的 `working_dir` 为准。支持 Python（含 Windows `py -3`）、Node、Ruby、Perl、Lua、sh/bash/zsh，以及 PowerShell 明确的 `-File` 调用。只接受已识别的少量解释器选项；内联代码、模块、预加载、uv 等包装命令、额外命令、管道、重定向、动态展开和交互式终端仍按普通规则审核。其他 Shell 不自动豁免。

免审不会开启“执行命令”、工具细选或技能能力，也不会扩大项目和子 Agent 的技能范围。只有当前可用 Skill 内的实际脚本文件可获得豁免。修改或新增脚本不会使免审失效；全局开关也覆盖新加入且可用的 Skill。脚本内部行为仍由脚本决定，免审不是文件或网络沙箱。关闭开关影响后续尚未执行的调用，不取消已启动进程。

## 系统技能与示例

系统技能位于应用数据目录的 `skills_system/`，随程序提供：

| 技能 | 用途 |
| --- | --- |
| `config` | 修改应用设置和头像，依赖“修改配置”能力。 |
| `skill-creator` | 创建或改进技能，依赖文件写入能力；测试脚本还需相应运行环境。 |
| `skill-installer` | 从本地目录或 Git 仓库安装技能，依赖文件读写；远程安装还需 Git 和网络。 |

`skills_examples/` 只存放示例，默认不加载。可用“导入”复制到“用户”后再使用：

| 示例 | 用途与主要依赖 |
| --- | --- |
| `baidu-search` | 百度搜索；Python 3、网络、`BAIDU_SEARCH_API_KEY`。 |
| `bailian-image` | 千问/万相文生图与图片编辑，支持本地图片及 URL；Python 3.10+、网络、`BAILIAN_IMAGE_API_KEY`，模型由 `BAILIAN_IMAGE_MODEL` 或 `--model` 指定。 |
| `exiftool-photo-search` | 按照片元数据搜索；Python 3.9+、ExifTool 和本地照片读取权限。 |
| `edge-tts-gen` | 生成语音文件；Python 3、网络、文件写入，以及 `edge_tts` 包、`edge-tts` 命令或 `uvx` 之一。 |
| `weather` | 天气查询；Python 3 和可访问 wttr.in 的网络。 |
| `ip-location` | 公网 IP 与粗略归属地；Python 3.8+ 和可访问 ipinfo.io 的网络。 |
| `obsidian-cli` | 操作 Obsidian 笔记库；已启用命令行接口的 Obsidian 桌面版和可用的 `obsidian` 命令。 |

系统和示例目录会在启动时从程序内置文件恢复。需要修改时，先复制或导入到“用户”或项目技能目录。

## 运行前的准备

- 查看技能的环境要求，以及随技能提供的 `SETUP.md`（如有）。Anas 不会因勾选技能而自动安装 Python、Git、ExifTool 等程序。
- 在“设置 > 环境”中编辑应用 `.env`。命令要读取其中的变量，还需开启相应 Agent 的“.env”能力。模型名称、账号和服务权限按实际使用的服务配置。
- 主动调用会直接加载完整 `SKILL.md`；模型自主加载技能或读取附带资料仍需要文件读取工具或执行命令，运行脚本通常需要“执行命令”。使用工具的模型需支持并开启“工具调用”，执行时沿用当前授权模式。

## 编写技能

Anas 使用 [Agent Skills 格式](https://agentskills.io/specification)。每个技能目录必须包含名称完全大写的 `SKILL.md`，还可包含 `scripts/`、`references/`、`assets/` 等资源。

例如 `photo-search/SKILL.md`：

```markdown
---
name: photo-search
description: 按照片元数据搜索本地照片；不用于识别画面内容。
compatibility: 需要 Python 3 和 ExifTool。
---

在此编写执行步骤、参数和结果说明。
```

- `name` 必须与目录名一致，使用小写英文字母、数字和单个连字符，最长 64 字符，首尾不能是连字符。
- `description` 必填，最长 1024 字符，说明用途及适用场景。
- `compatibility` 可选，填写时不能为空，最长 500 字符，用于说明环境依赖。
- 相对路径以 `SKILL.md` 所在目录为基准。需要用户提前准备的内容可放在 `SETUP.md`。
- 主动调用保留文件头和正文原文，不替换 `$ARGUMENTS`、`$0` 等占位符。技能应说明如何根据用户需求执行任务；`SKILL.md` 最多 1 MiB。

模型和用户的可用开关保存在 Anas 配置中，不写入技能文件。
