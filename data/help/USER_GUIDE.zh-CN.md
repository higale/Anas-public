# Anas 用户手册

语言：[English](./USER_GUIDE.en.md) | [中文](./USER_GUIDE.zh-CN.md)

GitHub：[higale/Anas-public](https://github.com/higale/Anas-public) · 开源协议：[MIT](https://github.com/higale/Anas-public/blob/main/LICENSE)

Anas 是一个本地桌面 Agent。你可以为不同项目配置上下文、工具、技能和子 Agent。配置、会话和记忆保存在本地；完成任务所需的内容会发送给你配置的模型服务。

在左下角菜单选择“帮助”，即可在右侧工作区阅读手册。用“目录”跳转章节，点击文内链接打开相关手册；关闭、放大或切换标签不影响聊天。

## 快速开始

1. 在“设置 > 模型”中添加模型服务，填写地址、模型名和密钥。
2. 在消息输入框底部的工具栏中选择模型。
3. 输入消息并发送；需要时可添加附件或选择项目。

## 项目与能力

在项目编辑窗口开启“定制能力”，可设置项目提示词、上下文、工具、技能和子 Agent。关闭后使用“设置 > 能力”中的默认配置，自定义选择会保留。默认配置不是总开关，开启定制的项目可以独立启用或关闭能力。“编码模式”独立控制开发工作方式，不会自动开启工具或提高授权范围。

- “文件读”“文件写”“记忆”和“自定义工具”可展开逐项选择，也可通过分组开关全选或取消。已删除或不可用的已选项仍可取消。
- 下文列出的工具都需要模型支持并开启“工具调用”。上下文类能力不需要工具调用；技能的实际使用还取决于读取文件和执行任务所需的工具。
- 能力选择决定提供什么工具，授权模式决定执行具体操作时是否需要确认。关闭“文件读”“文件写”或“网络访问”只撤下对应工具；执行命令和 MCP 仍可能提供同类操作。
- 修改只影响之后启动的任务；已经运行或等待恢复的任务继续使用启动时的选择。

顶部批量操作与单项开关不同：

- **全开**：启用全部内置能力和当前自定义工具，将 MCP 切换为“全部工具”，技能和子 Agent 切换为“使用默认”；在项目或默认能力设置中还会取消“限制子 Agent 能力”。不会启动全局停用的 MCP 服务。
- **全关**：关闭各项能力并清空内置、自定义和 MCP 工具选择；保留技能、子 Agent 的自定义名单。

在“设置 > 工具”左侧选择能力分组、自定义工具或 MCP，右侧显示工具列表；点击内置或 MCP 工具名查看参数和完整说明。

### 资料

向 Agent 提供“设置 > 通用”中的助手名称、角色、自定义指令和用户信息，帮助它按你的偏好回答。此项没有独立工具，也不赋予修改资料的能力；通过工具修改资料需要“修改配置”。子 Agent 是否接收资料，由自身能力及项目限制共同决定。

### 运行环境

向 Agent 提供在“设置 > 环境”中选中的系统、日期、目录、命令环境和自定义环境信息。此项只提供说明，不会安装程序或开启执行权限。

内置 rg 的说明需要同时开启“执行命令”和环境设置中的“内置命令”。关闭“运行环境”不会移除已经可执行的程序。自定义环境信息为空时的后台检测规则见[运行环境与环境变量](#运行环境与环境变量)。

### 项目信息

向 Agent 提供当前项目名称、源文件夹及路径使用说明，没有独立工具。关闭后，项目源文件夹仍作为工作目录和授权判断的依据；项目提示词独立控制，不随此项关闭。

### .env

决定执行命令和自定义工具时是否额外加载应用数据目录 `.env` 中的变量。文件在“设置 > 环境”中编辑。

此项没有独立工具。关闭后仍保留系统继承的环境变量，不清空 `.env` 文件，也不改变模型连接或共享 MCP 服务自身的配置。

### 后台工具

允许耗时的内置、自定义或 MCP 工具调用转到后台，让 Agent 查看、等待或取消。以下工具相互依赖，作为一组启停，不能逐个选择。关闭后，新调用等待完成再返回；已开始的调用不会因此取消。

| 工具 | 功能 |
| --- | --- |
| `read_call` | 查看本会话后台调用的状态、进度和终端信息。 |
| `read_call_output` | 按段读取后台调用的输出和结果。 |
| `wait_call` | 等待指定调用结束或等待超时。 |
| `cancel_call` | 请求取消指定后台调用。 |
| `write_call` | 向交互式终端发送文本、按键或调整尺寸。 |

`write_call` 需要启用“执行命令”或选中的交互式自定义工具。终端必须在启动时创建，不能事后给普通命令补接输入。子 Agent 的后台任务由“子 Agent”能力单独管理。

工具繁忙时会自动排队，无需重复提交。等待或执行较久的调用会返回编号，供 Agent 查看后续结果。

### 计划

提供 `write_todos`，让 Agent 建立和更新当前任务的计划及完成状态。适合多步骤任务；计划本身不执行命令或修改文件，实际工作仍需对应能力。

### 执行命令

让 Agent 通过系统命令运行程序、脚本、搜索、测试和构建。工具按实际命令程序命名，例如 macOS 的 `zsh`、Windows 的 `pwsh` 或 `powershell`；需要系统中存在可用的命令程序。

内置 rg 可用于文件和文本搜索，无需另行安装。脚本依赖的 Python、Node.js 等程序仍需自行准备。后续终端输入还需要“后台工具”；应用 `.env` 变量由 `.env` 能力独立控制。命令执行遵循当前对话的授权模式。

### 网络访问

提供 `http_request`，用于 HTTP/HTTPS 请求、接口调用、上传和下载。需要目标地址可访问，以及请求所需的认证信息；它不是浏览器自动化工具。

本工具可自行上传或下载文件，不依赖“文件读”“文件写”两个工具组，但文件访问仍遵循授权规则。MCP 连接和命令中的网络访问不由此开关控制。

### 修改配置

提供 `update_config`，让 Agent 按你的要求修改支持的应用设置，例如主题、字号和资料。目前只能修改应用设置中的受支持字段，不能通过它任意改写项目、模型或 MCP 配置文件。

不依赖“文件写”。“允许只读”和“严格授权”模式下，每次调用都需要确认；“完整访问”模式下直接执行。

### 用户交互

提供 `request_user_input`，让 Agent 弹出问题，供你选择选项或输入答案。适用于缺少信息、需要澄清或选择方案的情况；你可以取消，普通问题也可超时返回。

此项不依赖后台工具。关闭后 Agent 仍可在聊天中提问，但不能使用这个交互弹窗；工具执行前的授权确认不受此开关影响。

### 文件读

直接读取和检查本地文件，不依赖“执行命令”。读取项目外文件是否需要确认，由对话授权模式决定。

| 工具 | 功能 |
| --- | --- |
| `read_file` | 读取单个 UTF-8 文本文件，可指定行范围；不读取二进制内容。 |
| `read_multiple_files` | 批量读取多个文本文件，分别返回结果。 |
| `view_image` | 查看一张本地图片，将画面提供给当前模型。 |
| `view_multiple_images` | 一次查看最多 10 张图片，逐张标明路径，单个失败不影响其他图片。 |
| `list_directory` | 列出目录的直接子项。 |
| `directory_tree` | 分页查看目录结构，最多展开 64 层，不跟随符号链接。 |
| `get_file_info` | 查看类型、字节大小、时间；自动补充图片尺寸与方向、音视频时长和轨道信息。 |

图片工具需要当前模型支持视觉且开启视觉能力配置；支持 PNG、JPEG、WebP，不依赖“执行命令”。原图直接发送，不缩放或重新编码；单图最多 8 MiB，批量图片数据合计最多 16 MiB。

`get_file_info` 只读取文件信息，不识别画面内容；无需安装额外的媒体分析程序。

文本搜索可使用“执行命令”中的 rg；“文件读”本身没有独立搜索工具。

### 文件写

直接创建、修改、移动或删除本地文件，不依赖“执行命令”。可单独选择所需工具；需要先检查原文时，还应启用合适的读取工具。项目外写入通常需要确认，详见[工具与授权](#工具与授权)。

| 工具 | 功能 |
| --- | --- |
| `apply_patch` | 按原文上下文定位并修改文件，支持只预览不写入。 |
| `write_file` | 创建文本文件，或明确选择覆盖整个已有文件。 |
| `restore_file_edit` | 撤销有记录的整次 `apply_patch` 或 `write_file` 操作；恢复资料必须仍可用，遇到冲突不会直接覆盖。 |
| `get_file_edit_diff` | 查看 Agent 记录的文件改动，不等同于查看 Git 工作区差异；该工具本身只读。 |
| `create_directory` | 创建目录及所需的父目录。 |
| `move_file` | 移动或重命名文件、目录。 |
| `delete_file` | 删除文件或目录。 |

### 记忆

保存全局或当前项目的偏好、事实和经验。以下四项可独立选择，不互为前提。

| 子项 | 功能与依赖 |
| --- | --- |
| 自动召回 | 根据当前用户消息查找相关记忆并提供给模型；不调用工具，也不自动写入记忆。 |
| `read_memory` | 主动搜索或列出全局和当前项目的记忆。 |
| `save_to_memory` | 创建或更新记忆，选择全局或当前项目范围。 |
| `forget_memory` | 按记录 ID 删除记忆；不知道 ID 时可先查询。 |

只选“自动召回”即可使用相关旧记忆；关闭自动召回后，仍可启用查询或保存工具。取消选择不会删除记录，可在“设置 > 记忆”搜索、编辑或删除。

### 自定义工具

将你配置的程序或脚本作为工具提供给模型。需要准备对应的程序、依赖和账号；不依赖“执行命令”，交互式工具还需“后台工具”。配置和启用方法见[自定义工具管理](#自定义工具管理)。

### MCP

每个服务分别选择“全部工具”或具体工具。“全部工具”包含服务现在及以后新增的工具，并跟随服务的工具列表变化；取消后只使用明确勾选的工具。逐个选中当前所有工具仍属于具体选择，不会自动包含以后新增的工具。切换模式会保留之前的具体选择。

需要在“设置 > MCP”中启用对应服务并成功连接。项目勾选不会自动启动全局停用的服务。工具的作用、参数、依赖软件和账号由服务决定；它们不依赖同名的内置文件或网络工具开关。停用或不可用的已选工具仍可取消。

### 子 Agent

将独立任务交给其他 Agent，适合并行调查和分工。以下工具相互依赖，作为一组启停，不能逐个选择。

| 工具 | 功能 |
| --- | --- |
| `start_subagent` | 启动一个允许使用的子 Agent。 |
| `read_subagent` | 查看子任务的状态和过程。 |
| `wait_subagent` | 等待子任务进展、结束或需要确认。 |
| `cancel_subagent` | 取消指定子任务。 |

在“设置 > 子 Agent”中配置子 Agent。能力列表选择允许调用的子 Agent；“使用默认”采用全局默认启用项，自定义可选择默认关闭的条目，名单为空则无法启动。关闭能力会保留名单；此能力不依赖“后台工具”。

子 Agent 始终使用各自的能力配置，不继承“设置 > 能力”的默认值。子 Agent 可继续调用其他子 Agent，但候选范围不能超出最初项目允许的范围。“限制子 Agent 能力”则另行限制所有层级子 Agent 的上下文、工具和技能：勾选后，只允许项目与子 Agent 双方都启用的能力；未勾选时按子 Agent 自身配置执行。子 Agent 只收到交给它的任务内容，不会自动获得整个主对话。

### 技能

向 Agent 提供可用技能的名称、用途和说明文件位置，或让你通过 `/name` 快捷调用。技能是操作说明，没有独立的调用工具，也不会自动赋予文件、命令或网络能力。

“技能”开关只控制整体启停，不会全选列表；关闭后保留默认／自定义模式及具体选择。

“使用默认”遵循全局可用范围；自定义可分别选择“用户可用”和“模型可用”，包括全局默认关闭的技能。子 Agent 只配置模型使用范围。

主动调用会直接发送技能文件原文和来源路径，调用后的文字作为独立的用户需求；可展开技能记录查看实际发送内容。模型自主读取技能说明或附带资料需要 `read_file`、`read_multiple_files` 或可读取文件的“执行命令”；技能中的脚本还依赖命令程序、运行环境、所需工具和账号。选择技能不代表这些依赖已经满足。在“设置 > 技能”管理全局来源和可用范围；项目技能放在源文件夹的 `.agents/skills/` 下。导入、同名选择和编写方法见[技能手册](./AGENT_SKILLS.zh-CN.md)，安装要求见技能自己的 `SETUP.md`（如有）。

## 模型

支持 OpenAI 兼容和 Anthropic 兼容服务。在“设置 > 模型”中管理模型，在消息输入框底部切换使用。

按模型实际支持情况设置“视觉”和“工具调用”。关闭“工具调用”后，模型不能调用内置工具、MCP 工具或子 Agent；资料、运行环境、项目信息、技能目录和自动记忆召回仍按能力设置提供，已保存的选择不变。

## 工具与授权

项目“定制能力”选择可用工具，模型的“工具调用”决定能否调用。各项用途和依赖见[项目与能力](#项目与能力)。

对话支持三种工具访问模式：

- **允许只读**：默认模式，可直接读取项目外文件；项目外写入和无法确定为受支持只读操作的命令需要确认。
- **严格授权**：项目外读取也需要确认；只自动放行目标在项目内的受支持只读命令。
- **完整访问**：跳过执行前授权，可在会话“更多”菜单中撤销；撤销不打断已经开始的操作。

外部操作结果不确定时，仍需确认是否重试。等待确认的会话不能发送消息、编辑历史、重新生成或压缩，其他会话不受影响。

子 Agent 可在后台处理任务。点击其状态条可查看任务内容、工具调用和结果；主任务结束时，未完成或等待批准的子 Agent 会被取消。

## 运行环境与环境变量

“运行环境”中的“内置命令”默认开启，向 Agent 提供内置 rg 的使用说明。“检测系统环境”可更新系统命令信息，无需检测内置 rg。

“自定义环境信息”默认开启。启动时若已勾选且内容为空，会在后台检测并填入，不阻塞启动；已有内容不覆盖，检测期间取消勾选则不填入结果。

在“设置 > 环境”中编辑应用 `.env`，为命令、自定义工具和技能脚本准备变量。是否传入这些变量由相应 Agent 的 `.env` 能力决定。

## 自定义工具管理

在“设置 > 工具”选择“自定义工具”，可新增、编辑、删除、排序、导入和刷新。双击工具可编辑，“打开”定位目录；删除会将整个工具目录移到废纸篓。

每个工具目录包含 `TOOL.json` 和脚本或资源。用户工具保存在应用数据目录的 `tools/`；项目工具放在源文件夹的 `.agents/tools/`，仅供对应项目使用。编辑器配置名称、描述、JSON 参数规则和执行命令，不生成业务脚本或安装依赖。

“导入工具”可多选目录，默认打开内置示例目录，提供文本读取、文件 SHA-256 和 JSON 格式化示例，均需 Python 3。导入会复制到用户工具目录，不覆盖已有工具。

新增或导入后，需在默认、项目或子 Agent 的“自定义工具”能力中选中。子 Agent 使用独立选择，可开启“使用当前项目工具”，并遵循项目限制。同名时优先使用项目源文件夹顺序中的有效启用项，其次为用户工具。

命令在工具目录运行，相对路径从这里解析，例如 `scripts/run.py {{args}}`。`.py` 入口自动选择可用的 Python 3，也可明确指定解释器。独立参数 `{{args}}` 接收完整 JSON；`{{tool_dir}}` 表示工具目录绝对路径。命令只启动一个程序及固定参数，不支持管道或重定向。程序的标准输出作为结果返回模型；大段输入宜通过文件传递。

“交互式终端（PTY）”用于需要后续输入的程序，依赖“后台工具”，无需开启“执行命令”。普通文本结果不需要开启它。超时留空表示不限时，填写正整数秒可限制执行；等待输入也计入超时。取消或超时会终止进程树，但不会撤销已经发生的修改。

## MCP 设置

在“设置 > MCP”中添加和编辑服务，支持 stdio、HTTP 和 SSE。服务需启用并成功连接，模型需开启工具调用，项目需允许使用对应工具。

停用的服务仍可编辑；编辑运行中的服务会先停止它。“设置 > 工具”的工具目录按服务展示工具，项目中可进一步选择可用工具。

## 附件与语音输入

附件发送后会保存本地副本，原文件移动或删除不影响查看。默认只供当前一轮使用，点亮固定按钮后可在同一会话的后续轮次继续使用。

支持提取文本文件、PDF 和 docx 的文字。图片需要模型开启“视觉”；纯文本模型无法接收或查看图片内容。不支持的文件会标明未发送给模型。

点击麦克风按钮可调用 Windows 语音输入或 macOS 听写。开始、停止和识别语言由系统控制；macOS 需先在“系统设置 > 键盘 > 听写”中启用。确认系统听写已开始，输入结束后检查文字再发送。Anas 不录制或保存音频。

语音回复直接连接微软 Edge 在线语音服务，需要联网，待朗读文本会发送给微软。音色和语速可在设置中调整；音频仅在内存中暂存，停止播放或切换会话会取消未完成的合成并释放待播音频。

## 会话与上下文

Agent 页面左侧为项目和会话，中间为对话；帮助、子 Agent 和“文件改动”在右侧工作区打开。拖动分隔线调宽，或放大右栏；窄窗口使用抽屉。收起右栏或切换会话会保留标签和查看位置。关闭子 Agent 标签不会停止任务。

在“文件改动”中选择比较范围和文件，查看只读差异。顶部工具可切换行内／左右对比、折叠未修改区域。Git 比较支持工作区、暂存区、分支、标签和提交。历史原文不可用、二进制或超过 1 MB 的文件会提示无法显示差异。

“回合改动”显示当前会话有记录的文件修改，包含子 Agent 的改动，非 Git 目录也适用。默认比较该回合首次修改前与最后修改后的内容；“对比当前文件”改为比较当前磁盘内容，可能包含后续修改。消息下方的“本回合改动”可直接定位该回合。

点击“审核所选范围”可让 Agent 审核差异；发出的消息会显示实际审核指令和差异内容。

会话自动保存，侧栏显示用户发送消息的轮数；较早的消息可按需加载。执行过程显示工具调用、等待批准、失败原因和耗时。页面自动跟随新输出；向上滚动或展开详情时暂停，滚回底部或点击“滚动到底部”可恢复。

长对话会自动压缩上下文，也可通过输入框旁的上下文指示器手动压缩。指示器分类显示估算用量，预留输出空间单独显示，不计入已用上下文。

项目编辑窗口的“预览请求”可检查当前项目将提供给模型的上下文和工具。

## 本地数据与备份

默认数据目录为 `~/.gale<程序名>/`，标准 Anas 使用 `~/.galeAnas/`。复制并重命名程序可使用独立的数据目录。

也可启动时指定目录，例如 `Anas.exe "D:\Anas Data\Research"` 或 `--data-dir <路径>`。相对路径以启动目录为准，不能使用文件系统根目录。

备份保存为 zip 文件，包含用户工具和技能；项目源文件夹及外部引用的技能需另行备份。不包含运行日志、临时文件、开发请求追踪及界面缓存和登录状态。“设置 > 通用”中的“数据清理”可删除已结束的未置顶会话；置顶、运行中和等待批准的会话会保留。

## 故障排查

“设置 > Dev”提供开发者工具、日志查看，以及“控制台方式启动”。后者会保留当前数据目录并重启应用，在系统终端显示启动和运行输出。

- **模型调用失败**：检查服务地址、模型名、密钥和网络连接。
- **技能失败**：检查技能说明、环境变量和所需程序。
- **MCP 工具未出现**：确认服务已启用并成功连接、模型已开启工具调用，并检查项目工具选择。
- **操作等待确认**：按提示允许或拒绝；结果不确定时，只在接受可能重复执行的情况下重试。

### 启动恢复

启动加载失败时，恢复页列出出错文件，可查看错误详情、打开日志目录，并选择：

- **修复**：用默认值修正可确定的错误字段，保留有效设置；无法可靠修复的内容保持原样。
- **重置**：将所选配置恢复默认。**重置 `projects.json` 会同时清空所有项目的会话、消息、执行记录、任务恢复信息和记忆**；其他配置、技能、项目源文件和附件文件保留。

操作前自动保存原始数据到数据目录旁的 `Anas-Recovery/时间戳-随机后缀/`，保存失败则不修改。处理完成后重新启动。
